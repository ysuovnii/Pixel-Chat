# Pixel-Chat 💬

Pixel-Chat is a real-time web-based chat application built with **Node.js**, **Express**, and **EJS**. It follows the standard MVC (Model-View-Controller) architecture to ensure scalable and maintainable code. 

## 🚀 Features

* **Real-time Messaging**: Seamless communication between users.
* **MVC Architecture**: Clean separation of business logic, database models, and views.
* **Authentication**: Built-in middleware for secure user access.
* **Server-Side Rendering**: Fast and dynamic UI rendered dynamically using EJS.
* **Scalable Database Models**: Mongoose/MongoDB (or your chosen DB) integration ready.

## 🛠️ Tech Stack

* **Backend:** Node.js, Express.js
* **Frontend:** EJS (Embedded JavaScript templates), HTML, CSS, JavaScript
* **Routing:** Express Router
* **Architecture:** MVC (Model, View, Controller)

## 📁 Project Structure

```
Pixel-Chat/
├── controller/     # Handles the business logic and app functionalities
├── lib/            # Utility functions and library configurations
├── middleware/     # Custom middlewares (e.g., authentication, error handling)
├── models/         # Database schemas and models
├── routes/         # Express routes mapping URLs to controllers
├── views/          # EJS templates for the frontend UI
├── .gitignore      # Ignored files for Git
├── index.js        # Main application entry point
└── package.json    # Project metadata and dependencies
```
